# Ferramentas

Veículo expõe 1 ferramenta (todas somente leitura).

### 1. `veiculo_dados`
**Input**: `placa`, `renavam`

Consulta os dados de um veículo pela placa + RENAVAM (marca/modelo, ano, combustível, situação, restrições).

## Prompts de exemplo

```
Quais os dados do veículo de placa ABC1D23?
Esse carro tem restrição?
Qual meu saldo de créditos?
```
